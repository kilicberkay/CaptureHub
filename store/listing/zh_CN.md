# Chrome Web Store listing: CaptureHub (简体中文)

**Name:** CaptureHub

**Summary (132 characters max):**
截取可见区域、整页、选定区域或元素，然后用箭头、方框和马赛克进行标注。

## Description

CaptureHub 提供四种截图模式来截取网页，并配有标注编辑器，可在复制或保存前对截图进行标注。

亮点

- 四种截图模式：可见区域、整页、选定区域和元素。高度超过屏幕的选定区域和元素也会被完整截取。整页截图会滚动页面，并将各部分拼接为一张图片。固定的页眉和页脚只在图片顶部和底部各出现一次。
- 标注编辑器提供方框、椭圆、箭头、画笔、文字、马赛克、荧光笔、编号标记和裁剪工具。提供七种预设颜色、自定义颜色和取色器；线条、文字和画笔有五种尺寸（XS 至 XL）可选。标注可以选择和移动，每项更改都可以撤销和重做。
- 污点修复画笔和内容识别填充可从截图中去除文字、图标及其他不需要的细节。图片还可以旋转和调整大小。
- 复制到剪贴板，或保存为 PNG、JPEG 或 WebP。
- 每种截图模式都有键盘快捷键：Alt+Shift+V（可见区域）、Alt+Shift+F（整页）、Alt+Shift+R（选定区域）和 Alt+Shift+E（元素）。通过工具栏图标的右键菜单，可以使用截图模式、历史记录和设置。
- 截取可见区域和整页前可设置延迟（可选），以便先打开菜单和工具提示。
- 最近截图的历史记录保存在您的设备上，并包含每张截图的页面标题和网站。您可以搜索历史记录、在编辑器中重新打开截图，或在文件夹中显示已下载的文件。
- 设置备份（导出和导入）、恢复默认设置、15 种界面语言，以及浅色、深色或跟随系统的主题。
- 无需账户。CaptureHub 不收集任何数据，不使用分析统计，也不发出任何网络请求。截图、历史记录和设置仅保存在您的设备上，不会上传任何内容。

使用方法

1. 打开要截图的页面。
2. 按 Alt+Shift+V 截取可见区域，按 Alt+Shift+F 截取整页，按 Alt+Shift+R 截取选定区域，或按 Alt+Shift+E 截取元素。工具栏弹出窗口和工具栏图标的右键菜单同样提供这四种模式，以及历史记录和设置。
3. 在编辑器中标注截图，然后复制或保存为 PNG、JPEG 或 WebP。

在 macOS 上，快捷键为 Option+Shift+…；可在 chrome://extensions/shortcuts 中更改。
