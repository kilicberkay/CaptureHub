# Chrome Web Store listing: CaptureHub (简体中文)

**Name:** CaptureHub

**Summary (132 characters max):**
截取可见区域、整页、选定区域或元素，然后用箭头、方框和模糊进行标注。

## Description

CaptureHub 提供四种方式截取网页屏幕截图，并配有编辑器，可在复制或保存前进行标注。

亮点

- 支持截取可见区域、整页、选定区域和元素；超过屏幕高度的元素和区域也会完整截取。整页截取时会滚动页面并拼接各部分，固定的页眉和页脚保持在原位。
- 编辑器支持方框、椭圆、箭头、画笔、文字、像素化、荧光笔、编号标记和裁剪。提供七种预设颜色、自定义颜色和取色器，以及五种尺寸（XS 至 XL）。可选择并移动任意标记，每项更改都能撤销和重做。
- 污点修复画笔和内容感知填充可从截图中去除文字、图标或光标。支持旋转和调整大小。
- 复制到剪贴板，或保存为 PNG、JPEG 或 WebP。
- 每种模式都有快捷键（Alt+Shift+V、F、R、E），工具栏图标还有右键菜单。
- 可选的截取延迟，方便先打开菜单和工具提示。
- 本地保存最近截图的历史记录，包含页面标题和网站；可搜索、重新打开截图，或在文件夹中显示已下载的文件。
- 设置备份（导出和导入）、重置、15 种界面语言，以及浅色、深色或跟随系统的主题。
- 无需账户，没有分析统计，不会上传任何内容。
