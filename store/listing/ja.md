# Chrome Web Store listing: CaptureHub (日本語)

**Name:** CaptureHub

**Summary (132 characters max):**
表示領域、ページ全体、範囲、要素をキャプチャし、矢印・枠・モザイクで注釈を付けられます。

## Description

CaptureHubは、4つのキャプチャモードでウェブページのスクリーンショットを撮影します。コピーや保存の前にスクリーンショットへ注釈を付けるための注釈エディターを備えています。

主な機能

- 4つのキャプチャモード：表示領域、ページ全体、選択範囲、要素。画面より縦に長い選択範囲や要素も全体をキャプチャします。ページ全体のキャプチャでは、ページをスクロールして各部分を1枚の画像につなぎ合わせます。固定ヘッダーと固定フッターは、画像の上端と下端に1回だけ表示されます。
- 枠、楕円、矢印、ペン、テキスト、モザイク、蛍光ペン、番号マーカー、切り抜きの各ツールを備えた注釈エディター。定義済みの7色、カスタムカラー、スポイトを使用でき、線・テキスト・ブラシのサイズは5段階（XS〜XL）から選べます。注釈は選択して移動でき、すべての変更を元に戻したりやり直したりできます。
- スポット修復ブラシとコンテンツに応じた塗りつぶしで、スクリーンショットから文字、アイコン、その他の不要な部分を取り除けます。画像の回転とサイズ変更にも対応しています。
- クリップボードへのコピー、または PNG・JPEG・WebP 形式で保存。
- キャプチャモードごとのキーボードショートカット：Alt+Shift+V（表示領域）、Alt+Shift+F（ページ全体）、Alt+Shift+R（選択範囲）、Alt+Shift+E（要素）。ツールバーアイコンの右クリックメニューから、キャプチャモード、履歴、設定にアクセスできます。
- 表示領域とページ全体のキャプチャでは、撮影前に任意の遅延を設定でき、メニューやツールチップを先に開いておけます。
- 最近のキャプチャの履歴は、各キャプチャのページタイトルとサイトとともに端末に保存されます。履歴を検索したり、キャプチャをエディターで再び開いたり、ダウンロードしたファイルをフォルダーで表示したりできます。
- 設定のバックアップ（エクスポートとインポート）、初期設定へのリセット、15のインターフェース言語、ライト・ダーク・システムのテーマ。
- アカウントは不要です。CaptureHubはデータを収集せず、アナリティクスを使用せず、ネットワークリクエストも送信しません。キャプチャ、履歴、設定は端末内にのみ保存され、何もアップロードされません。
