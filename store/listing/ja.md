# Chrome Web Store listing: CaptureHub (日本語)

**Name:** CaptureHub

**Summary (132 characters max):**

## Description

CaptureHubはウェブページのスクリーンショットを4つの方法で撮影でき、コピーや保存の前に注釈を付けるエディターを備えています。

主な機能

- 表示領域、ページ全体、範囲、要素のキャプチャに対応。画面より高い要素や範囲も全体を撮影できます。ページ全体のキャプチャではページをスクロールして各部分をつなぎ合わせ、固定のヘッダーとフッターは所定の位置に残します。
- 枠、楕円、矢印、ペン、テキスト、モザイク、蛍光ペン、番号マーカー、切り抜きを備えたエディター。定義済みの7色、カスタムカラー、スポイト、5段階のサイズ（XS〜XL）。任意の注釈を選択して移動でき、すべての変更を元に戻したりやり直したりできます。
- スポット修復ブラシとコンテンツに応じた塗りつぶしで、スクリーンショットから文字・アイコン・カーソルを消去できます。回転とサイズ変更も可能です。
- クリップボードへのコピー、または PNG・JPEG・WebP 形式で保存。
- 各モードのショートカット（Alt+Shift+V、F、R、E）と、ツールバーアイコンの右クリックメニュー。
- キャプチャ前の遅延を設定でき、メニューやツールチップを先に開けます。
- 最近のキャプチャをページのタイトルとサイトとともに履歴に保存。検索、再表示、ダウンロードしたファイルのフォルダー表示ができます。
- 設定のバックアップ（書き出しと読み込み）、リセット、15言語のインターフェース、ライト・ダーク・システムテーマ。
- アカウント不要、アナリティクスなし、データのアップロードは一切ありません。
